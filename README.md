# TokenCoin 双向通道 Demo 0.4.2

双方安装同一个插件，复制私有邀请即可连接，无需手动配置局域网或VPN。推理经供应方节点，文件和工具在使用者电脑执行。

本版在同一通道同时提供**朋友独立周预算10%（真实校准后的经验估算）**与**账号官方周剩余30%保底**。本人其他请求不扣减朋友10%；本人使用会影响额外的账号30%保护。官方读数异常、预算触达或授权到期时暂停。估算误差和官方延迟可能导致超调，不保证精确停在10.00%或剩余30.00%。

## 下载与安装

下载[v0.4.2实验安装包](https://github.com/youshangdekongjunsiling-spec/tokencoin-channel/releases/tag/v0.4.2)，完整解压，保留隐藏的.agents目录。

- Windows x64：双击install-windows.cmd，然后start-panel-windows.cmd。
- Apple芯片Mac：在解压目录执行bash install-macos.command，然后bash start-panel-macos.command；使用原生ARM64 Python。
- 需要Python 3.10+和Codex CLI，安装器校验固定版本iroh 1.2.0。
- 升级使用新包重新安装并新开Codex会话。侧栏位置取决于宿主；独立面板提供相同功能。每台机器只开一个面板。

## 建立通道

1. 供应方完成官方账号授权，选择快速连接、真实订阅及30%保底，明确本次共享截止并启动。
2. 核对账号套餐、模型、档位和周窗口，导入自己的真实校准profile及有效期。发布包不包含个人参数。
3. 选择“朋友周比例（估算）+ 账号30%保底”，填10%和邀请期限，私下发送生成的邀请。
4. 朋友粘贴新邀请并取未使用的简称，选择独立工作目录，先只读运行“只回答连接成功”；通过后再做示例副本的修复和测试。
5. 两端保持在线。期限最长24小时且不晚于官方周重置，重启不续期，随时可撤销。反向共享另建独立通道。

供应方可以看到模型请求上下文。账号凭证留在供应方；邀请含受限通行证，不应公开。iroh优先自动直连，必要时用加密公共中继；中继适合试用、有限流且无可用性保证。
