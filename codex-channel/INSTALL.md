# TokenCoin 双向通道 · 安装与首次连接

双方下载同一份完整 ZIP 并解压。需要 Python 3.10+、Codex CLI，以及双方互通的可信局域网或加密 VPN。

## 安装

Windows：在下载包根目录双击 `install-windows.cmd`。macOS：在终端进入下载包根目录，运行 `bash install-macos.command`。安装器会为当前机器选择正确的 Python 路径，然后注册本地插件市场。

重新打开 Codex，查找侧栏的 **TokenCoin 双向通道**。插件通过官方 MCP 全局入口声明按钮，具体位置由宿主版本决定。若宿主未刷新，重启 Codex；也可通过插件工具打开，或用下载包的 `start-panel` 启动器在本机浏览器打开同一界面。不要同时开启多个控制面板进程。

## 第一次双向使用

1. 两人分别安装。谁要提供 Codex 订阅调用，谁在自己的面板点击“登录我的 Codex 账号”。只使用朋友节点时不需要提供方的登录文件。
2. 先让双方私网互通。异地可用自己的加密 VPN；填写自己设备的实际私网 IPv4，不使用示例 IP。仅允许朋友设备访问共享端口，适配器的 18317 端口始终只绑定本机。
3. 在“提供我的额度”填写显示名、模型、私网 IP，确认可信私网后启动。看到“共享中”再生成限时、限次数的邀请。
4. 私下发邀请 JSON 给朋友。朋友在“使用朋友的额度”填写简称、导入文件、检查连接。
5. 朋友选择提供者、已有的本机工作目录、任务和文件权限，点击运行。模型调用走供应者，读文件、写代码和测试在消费者本机执行。
6. 反方向使用时，朋友也启动自己的共享并发邀请给你。两个方向分别授权、分别计数、分别撤销。

首次只用不含私密数据的练习目录。供应者能看到经通道发送的上下文。共享的是调用入口，账号凭证不交给朋友。

## 运行边界

- 面板启动独立 Codex CLI 任务，不自动改写当前桌面对话的模型提供者。
- 请求次数不是任务次数或金额限额；一个任务可含多轮模型请求。
- 关闭供应服务会使后续请求不可达；撤销邀请拒绝后续新请求，已受理请求可能完成。
- 真实订阅路径已在本人 Windows 本机验证。跨人使用范围由上游服务规则决定。macOS 与双机仍需实机验证。
- API Key 路径保留原有高级 CLI 配置，当前图形面板支持订阅与 mock。
- 此版本没有公网发现、自动打洞或中继服务器。面板中的连接依赖已建立的私网。
- 升级保留个人状态目录，勿将其放进 GitHub、共享盘或同步盘。

完整命令行指南见 README.md。架构入口为 scripts/dashboard.py（本机管理）、scripts/mcp_server.py（侧栏）、scripts/channel.py（推理通道）。
