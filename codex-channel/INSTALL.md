# TokenCoin 0.4.2 · 双人试用安装指南

双方下载同一份完整ZIP并解压，需要Python 3.10+和Codex CLI。快速连接支持Windows x64和Apple芯片Mac，不用配置局域网、VPN或路由器端口。

## 安装并打开面板

Windows：双击包根目录的 install-windows.cmd，完成后双击 start-panel-windows.cmd。

Apple芯片Mac：在解压目录打开终端，运行 bash install-macos.command，然后运行 bash start-panel-macos.command。使用原生ARM64 Python；Intel/Rosetta Python不匹配本版网络组件。

安装器下载固定版本iroh 1.2.0并校验SHA256。已有旧包时使用新包重新安装，再新开Codex会话；个人状态目录与安装包分开。不要同时运行两个面板。宿主侧栏位置及刷新时机可能不同，独立面板提供相同功能。

## 提供额度的一方：10%估算预算，加账号30%保底

1. 点“登录我的Codex账号”，在官方页面授权。已授权账号无需重复登录。
2. 选择“快速连接”和“真实Codex订阅”，勾选保留30%官方周余量，明确设置本次共享截止，再启动。截止必须在未来24小时内，且不晚于官方周重置。
3. 在校准区导入供应方自己采集、经完整官方任务账单校准并独立验证的profile。核对账号、套餐、模型、推理和速度档位及官方周窗口，授权截止与本次试用一致。发布包不附带个人校准文件。
4. 选择“朋友周比例（估算）+ 账号30%保底”，填朋友备注、10%和邀请期限，生成邀请。24小时填写1440分钟；实际截止取邀请期限、校准授权、保护授权和周窗口中的最早值。
5. 私下发完整邀请。保持电脑、网络和供应服务在线。到期即停止，不自动续期；随时可撤销。

朋友的10%以整周额度100%为分母。网关按朋友独立任务记录输入、缓存、输出token，使用真实校准参数估算消耗；本人其他请求不会计入这10%。另外，账号官方总周剩余<=30%或读数异常时停止共享，本人使用也可能触发此保护。

估算参考范围来自已观察验证误差，不是置信区间或未来硬上界。单次已接受请求、官方读数延迟和取消传播可能导致超调，不能保证恰好停在10.00%或剩余30.00%。

## 使用朋友额度的一方

1. 无需登录供应方账号。打开面板，给这份新邀请取一个未用过的朋友简称，粘贴完整邀请串，点“连接朋友”。旧邀请到期后不能复用。
2. 选中朋友节点，填写自己电脑上已有的独立工作目录，以只读模式发送“只回答连接成功”。
3. 短句通过后，在下载包示例的副本中测试读取、修复小bug和运行测试；需要修改时再允许这个独立目录写入。
4. 反馈系统、Python/Codex版本、当前步骤和去敏报错。不要转发邀请、登录文件或私密代码。

模型请求通过加密通道到供应方，文件和命令在使用者电脑执行。供应方能看到模型上下文，首次测试请用独立演练目录。反向共享时交换角色、另建授权，两个方向独立撤销。

## 停止、重启与重新授权

重启保留原截止时间，不能借重启延长试用。到期后只有新的明确授权才能设置新截止；若仍有未撤销、未到期的受保护邀请，程序拒绝修改保护截止。跨周、账号/套餐变化或读数异常会暂停。不要切换旧次数模式绕过保护。

连接失败先确认双方在线、邀请有效且未撤销。iroh自动尝试直连，必要时使用端到端加密公共中继；中继有限流、无可用性保证。邀请是受限通行证，仅私下传递。

临时“保留30%官方周余量”仍可单独使用，它没有朋友独立10%预算。API Key路径保持原有模式。
