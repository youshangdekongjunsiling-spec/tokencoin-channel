# TokenCoin 0.3 · 复制邀请即可连接

双方下载同一份完整 ZIP。需要 Python 3.10+ 和 Codex CLI。快速连接支持 Windows x64 与 Apple 芯片 Mac（原生 ARM64 Python），无需配置局域网、VPN 或路由器端口。

## 安装

Windows：双击下载包根目录的 `install-windows.cmd`。

Mac：终端进入下载包根目录，运行 `bash install-macos.command`。

安装器下载固定版本 iroh 1.2.0，校验官方 SHA256，安装到个人 TokenCoin 目录，不修改全局 Python。使用 Intel Python / Rosetta 的 Mac 请切换到 ARM64 Python；当前不打包 Intel Mac 网络组件。

重新打开 Codex，查找 **TokenCoin 双向通道**。插件声明官方 MCP 侧栏入口，宿主按钮位置及当前窗口刷新仍需验证。下载包的 `start-panel-windows.cmd` 或 `bash start-panel-macos.command` 可直接打开同一控制面板。每台机器同时只开一个面板。

## 两个人怎么连接

1. 额度提供者点击“登录我的 Codex 账号”，在官方页面完成本人授权。已授权者无需重复登录。先演练可选“模拟演练”。
2. 保持默认“快速连接”，填写显示名、模型，点“启动共享”。等到“共享中”。
3. 设置朋友备注、请求次数和有效期，点“生成邀请串”，再点“复制邀请”。通过私密方式发给朋友。
4. 朋友在右侧填写简称，例如 `alice`，粘贴整段 `tokencoin://connect#…`，点“连接朋友”。邀请串直接粘贴到插件；本版尚未注册操作系统点击唤起功能。
5. 朋友选择你作为额度提供者，填写自己电脑上的工作目录和任务，点击运行。模型调用走你的节点，文件和命令工具在朋友电脑执行。
6. 你要用朋友的额度时，朋友在左侧启动自己的共享并给你发另一份邀请。双方共用同一个插件，每个方向独立授权、计数和撤销。

双方保持电脑、插件面板和供应节点在线。重开面板后，供应者再次“启动共享”；消费者点击“检查连接”或发起新任务时自动重建本机转接。未过期、未撤销的邀请可以继续使用。

## 网络与授权

插件通过 iroh 自动建立端到端加密连接：可用时直连，必要时使用公共中继。中继无法解密通道内容，但能观察 IP、连接时间和流量大小；供应方仍能看到模型请求上下文。公共中继适合开发试用，有限流且无可用性保证；正式长期服务需要单独评估中继资源。

账号登录凭证留在供应方电脑。邀请串是一份受限的可重复使用通行证，包含高熵授权值；只私下发给指定朋友，不贴进 AI 对话、日志或公开网站。当前使用长邀请串，尚无六位数字配对码、好友确认流程或设备目录。

- 次数按获准的模型请求尝试扣除，一个开发任务可能用多次。不是金额或 token 上限。
- 撤销拒绝后续新请求；已接受的请求可能完成。额度耗尽后，快速通道也拒绝新的连接请求。
- 每个 HTTP 请求通过独立 QUIC 流传送，持续转发 SSE 输出；传输中断不会自动重放模型请求。
- 两端管理面板、消费者转接、供应网关及账号适配器均保持本机访问。外网连接只接入受限的加密通道。
- 面板启动独立 Codex CLI，不切换当前桌面对话的模型提供者。API Key 路径保留高级 CLI 方式。
- 私网 / VPN 模式仍在高级选项中。旧命令行示例见 README.md。

本版具体机器验证见发布包 `docs/verification.json`。macOS 实机、朋友异地双机与不同 NAT/网络限制下的表现仍待试用；同机测试不代表穿透成功率或跨机延迟。
