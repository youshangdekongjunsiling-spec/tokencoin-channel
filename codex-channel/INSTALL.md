# TokenCoin 0.4.1 · 双人试用安装指南

双方下载同一份完整ZIP并解压，需要Python 3.10+和Codex CLI。快速连接支持Windows x64和Apple芯片Mac，不用配置局域网、VPN或路由器端口。

## 先安装并打开面板

Windows：双击包根目录的 `install-windows.cmd`，完成后双击 `start-panel-windows.cmd`。

Apple芯片Mac：在解压目录打开终端，运行 `bash install-macos.command`，然后运行 `bash start-panel-macos.command`。需使用原生ARM64 Python；Intel/Rosetta Python不匹配本版网络组件。

安装器下载固定版本iroh 1.2.0并校验SHA256，安装到个人TokenCoin目录。重开Codex后也可查找“TokenCoin双向通道”入口；宿主侧栏位置及刷新时机可能不同。每台机器只开一个面板。

## 提供额度的一方

1. 点“登录我的Codex账号”，在官方页面授权。已授权的账号无需重新登录。
2. 保持“快速连接”和“真实Codex订阅”，勾选“共享期间给自己保留30%官方周剩余额度”，点“启动共享”。
3. 官方表读取成功且剩余高于30%后，选择“临时试用·保留30%官方周余量”，填朋友备注和邀请期限，生成邀请串。
4. 私下把完整邀请发给指定朋友。保持电脑、面板和供应服务在线。邀请不能晚于当前官方周窗口或保护授权截止；不会自动续期。
5. 随时可撤销该朋友，或停止整个共享节点。

临时模式按账号官方整周余量保护，本人并行使用也会触发暂停。它不代表给朋友精确分配10%。官方读数延迟及已接受请求可能继续扣量，不能保证精确停在30.00%。读数失效时暂停；不要通过切换旧次数模式绕过保护。

## 使用朋友额度的一方

1. 你不用登录朋友账号。打开面板，填写朋友简称并粘贴完整 `tokencoin://connect#…`，点“连接朋友”。
2. 选中朋友节点，填写自己电脑上的一个独立工作目录，先以只读模式发送“只回答连接成功”。
3. 短句通过后，在下载包的示例副本中测试读取、修复小bug和运行测试；需要修改时再选择允许该独立目录写入。
4. 记录系统、Python/Codex版本、当前步骤和去敏报错。不要转发邀请、登录文件或私密代码。

模型请求通过加密通道到供应方，文件和命令在使用者电脑执行。供应方能看到请求上下文，因此先用独立演练目录。反向共享时交换角色、另建授权，两个方向独立撤销。

## 校准后的独立周预算

“周额度比例（估算）”保留，需要真实、完整任务标签拟合并独立验证后导入profile。默认目标10%；没有真实profile时拒绝创建该模式邀请。经验误差范围不是置信区间或未来硬上界，完整官方任务账单可替换估算。旧4条记录不完整，新12任务已采集但官方完整标签仍待返回；安装包不附带虚构系数。

## 网络与停止

iroh自动尝试直连，必要时使用端到端加密公共中继。公共中继适合开发试用，有限流且无可用性保证。邀请含受限可重复使用的通行证，只私下发送。

重启供应端时需要重新开启已选的保护；省略保护不能放行已有受保护邀请。跨周、账号/套餐变化和读数异常会暂停，不自动续期。消费者连接失败时先确认双方在线、邀请未到期且未撤销。

本版验证见发布包 `docs/reserve-verification.json`；此前Windows本机真实CLI已完成读文件、修补和测试。macOS实机、异地双机和真实独立10%预测精度仍待验证。
